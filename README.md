# Caesar Cipher

This is a simple Python project that can encode and decode messages using the Caesar Cipher method. I made it to practice Python basics such as loops, functions, and working with strings.

## How to run

1. Download the project files.
2. Make sure Python 3 is installed.
3. Open a terminal in the project folder.
4. Run `python main.py` (or `python3 main.py`).
5. Choose `encode` or `decode`, enter a message, and type a shift number.

## Files

- `main.py` – the main program.
- `alphabet.py` – the alphabet used for shifting letters.
- `art.py` – a small text logo.
